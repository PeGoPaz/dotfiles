# Полное руководство: от нуля до работающей системы

Это руководство для человека, который никогда не пользовался Linux. Оно объясняет
всё: что такое Arch, что такое Hyprland, как поставить систему с флешки, что делает
этот конфиг и как им пользоваться каждый день.

Английский README рядом — короткая справка для тех, кто уже в теме. Этот файл —
длинный и с объяснениями.

---

## Часть 1. Что это всё такое

### Linux, дистрибутив, Arch

**Linux** — это ядро операционной системы: то, что разговаривает с железом. Само по
себе оно бесполезно, как двигатель без машины.

**Дистрибутив** — ядро плюс всё остальное: программы, оболочка, способ ставить софт.
Ubuntu, Fedora, Arch — это дистрибутивы.

**Arch Linux** отличается двумя вещами:

- **Rolling release.** Нет версий вроде «Windows 10 → Windows 11». Обновления
  приходят непрерывно, каждый день. Система всегда свежая, но и ломается чаще, чем
  у дистрибутивов с фиксированными релизами.
- **Ничего лишнего.** Arch ставит голую систему, а ты добавляешь только то, что
  нужно. Отсюда и репутация «сложного» — он ничего не решает за тебя.

**pacman** — менеджер пакетов Arch. Пакет это программа плюс её зависимости.
Вместо скачивания .exe ты говоришь `pacman -S firefox`, и система сама всё ставит.

**AUR** (Arch User Repository) — склад рецептов сборки от пользователей. Мощно, но
код там чужой и не проверенный. **В этом конфиге AUR не нужен вообще** — всё берётся
из официальных репозиториев и из репозитория CachyOS.

### CachyOS

CachyOS — это Arch, собранный ради скорости. Проверено по их сайту:

- Все пакеты пересобраны под современные наборы инструкций процессора
  (x86-64-v3, x86-64-v4, Zen4) с оптимизацией LTO; ключевые — ещё и PGO/BOLT.
  На практике это несколько процентов производительности бесплатно.
- Своё ядро с настроенным планировщиком, плюс варианты BORE, sched-ext, BMQ и RT.
  Планировщик решает, какой программе дать процессор — от него зависит
  «отзывчивость» системы.
- Графический установщик на базе Calamares — то есть ставится мышкой, а не
  вручную из командной строки, как классический Arch.
- Больше 17 рабочих окружений на выбор при установке, включая Hyprland.
- Свой подписанный репозиторий пакетов вдобавок к репозиториям Arch.

Проще говоря: сложность установки Arch убрана, скорость добавлена.

### Оконный менеджер и Hyprland

В Windows и macOS окна плавают: ты их двигаешь, растягиваешь, они наезжают друг на
друга. Это **стековый** режим.

**Тайлинг** — другой подход. Окна не накладываются, а делят экран между собой
автоматически. Открыл терминал — он занял весь экран. Открыл браузер — экран
разделился пополам. Третье окно — делится дальше. Ты не двигаешь окна мышкой,
ты переключаешься между ними клавишами.

Плюсы: ни пикселя впустую, руки не уходят с клавиатуры, ничего не теряется под
другими окнами. Минус: первые дни непривычно.

**Hyprland** — тайловый композитор для Wayland. Два слова, которые надо понять:

- **Wayland** — современная замена X11, системы отрисовки окон в Linux. Wayland
  плавнее, безопаснее и лучше дружит с дробным масштабированием.
- **Композитор** — программа, которая и раскладывает окна, и рисует их. В Wayland
  это одна программа, а не две, как раньше.

Hyprland известен красивыми анимациями и гибкостью. В этом конфиге анимации оставлены,
но укорочены до ~200 мс — заметно, но не тормозит.

> **Важно про формат конфига.** С версии 0.55 Hyprland перешёл с собственного языка
> hyprlang (`hyprland.conf`) на **Lua** (`hyprland.lua`). Старый формат объявлен
> устаревшим и будет удалён. Этот конфиг написан на Lua, то есть на актуальном
> формате. Если найдёшь в интернете гайд с `hyprland.conf` — он про старый формат.

### Воркспейсы

Воркспейс — это виртуальный рабочий стол. Их здесь 6, всегда на виду в панели снизу.
Смысл в том, чтобы раскладывать дела по столам: на первом браузер, на втором код,
на третьем мессенджеры. Переключение — `SUPER+цифра`, мгновенно.

**`SUPER`** — это клавиша с логотипом Windows. В Linux её зовут Super. Она здесь
главный модификатор: почти все сочетания начинаются с неё.

## Часть 2. Установка

### Перед началом

Выпиши на бумажку или на телефон: **как откатиться**, если что-то пойдёт не так
(раздел «Если что-то сломалось» ниже). На новом ноутбуке без второго компьютера
под рукой это спасает нервы.

### Установка CachyOS

1. Вставь флешку, включи ноутбук, жми `F2` (или `Del`) чтобы попасть в BIOS.
2. Отключи **Secure Boot**. Найди загрузку с USB, поставь флешку первой.
3. Загрузись с флешки. Появится живая система — можно потыкать, ничего ещё не
   установлено.
4. Запусти установщик (иконка на рабочем столе).
5. При выборе рабочего окружения укажи **Hyprland**.
6. **Загрузчик** — выбери **Limine** (конфиг рассчитан на него).
7. **Шифрование диска** — если включаешь, придумай пароль и запомни его. Без него
   данные не восстановить.
8. Создай пользователя, задай пароль, дождись конца установки, перезагрузись.

После первой загрузки ты попадёшь в **штатный Hyprland от CachyOS** — он уже
настроен и работает. Наш конфиг пока не установлен.

### Что нужно знать про терминал

Терминал — окно, куда пишут команды. Открывается `SUPER+Return` — и в штатном
конфиге CachyOS, и в нашем. По умолчанию у CachyOS это alacritty, у нас Ghostty.
`SUPER+Q` в обоих закрывает окно.

Базовое:

- `pacman -S имя` — поставить пакет (нужен `sudo` впереди)
- `sudo` — «выполнить от администратора», спросит твой пароль
- `cd путь` — перейти в папку, `ls` — показать содержимое
- `~` — сокращение для твоей домашней папки (`/home/имя`)
- Стрелка вверх — предыдущая команда
- `Ctrl+C` — прервать зависшую команду

### Установка пакетов

Открой терминал и выполни одной строкой:

```bash
sudo pacman -S --needed hyprland hyprpaper hypridle hyprlock hyprsunset waybar \
  ghostty fuzzel mako ranger firefox grim slurp cliphist wl-clipboard \
  brightnessctl playerctl pavucontrol libnotify asusctl rog-control-center \
  supergfxctl nvidia-prime ttf-jetbrains-mono-nerd stow git
```

`--needed` значит «не переустанавливать то, что уже стоит».

Всё это — готовые бинарные пакеты, ничего не собирается из исходников.
`supergfxctl` приходит из репозитория самого CachyOS (в репозиториях Arch его нет).

Ещё два шага, требующих прав администратора:

**Драйвер NVIDIA.** RTX 5060 — архитектура Blackwell, она работает **только** на
открытых модулях. Выбора тут нет:

```bash
sudo pacman -S --needed nvidia-open-dkms
```

**Параметр ядра.** Может понадобиться `nvidia_drm.fbdev=1`. Прописывается в
`/etc/default/limine`, затем `sudo limine-update`. На драйверах 545 и новее
`nvidia_drm.modeset=1` уже включён по умолчанию, дописывать его обычно не нужно.

### Установка конфига

CachyOS кладёт свои конфиги waybar и mako в твою домашнюю папку. Это настоящие
файлы, а **stow** (программа, которая расставляет симлинки на файлы из репозитория)
отказывается их перезаписывать. Поэтому сначала отодвинь их:

```bash
mv ~/.config/waybar ~/.config/waybar.stock
mv ~/.config/mako ~/.config/mako.stock
```

Теперь забирай конфиг:

```bash
git clone https://github.com/PeGoPaz/dotfiles.git ~/dotfiles
cd ~/dotfiles
stow hypr ghostty waybar fuzzel mako nvim
```

Положи любую картинку обоями:

```bash
mkdir -p ~/Pictures/wallpapers
# скопируй сюда картинку и назови wallpaper.jpg
```

Выйди из сессии и зайди снова (`SUPER+Backspace` → `logout`). Затем проверь:

```bash
~/.config/hypr/scripts/check.sh
```

Скрипт напечатает `PASS` / `FAIL` / `SKIP` по каждому пункту. `SKIP` — это не
ошибка, а «проверь сам»: запустить игру, дождаться ухода в сон.

### Если что-то сломалось

**Hyprland не падает от ошибки в конфиге.** Он запустится и покажет список ошибок
прямо на экране. Если ошибка была настолько ранней, что не зарегистрировался ни один
бинд, включится аварийный режим с тремя клавишами:

| Клавиша | Действие | Работает? |
|---|---|---|
| `SUPER+M` | выйти из Hyprland | да |
| `SUPER+R` | запустить hyprland-run | да |
| `SUPER+Q` | первый найденный терминал | скорее всего |

`SUPER+Q` ищет по зашитому списку: kitty, alacritty, foot, wezterm, gnome-terminal,
xterm. Ghostty в него не входит. Но CachyOS использует alacritty как штатный
терминал, так что он у тебя, скорее всего, уже стоит — и тогда `SUPER+Q` сработает.
Гарантии нет: ни один пакет не тянет alacritty как зависимость. Надёжные выходы —
`SUPER+M` и переход в текстовую консоль по `Ctrl+Alt+F2`.

Проверить заранее можно так: `which alacritty`. Если пусто, а подстраховка нужна,
поставь любой терминал из списка — например `sudo pacman -S foot`.

**Полный откат** делается одной командой. Наш конфиг называется `hyprland.lua`, а
конфиг CachyOS — `hyprland.conf`, и мы его не трогали. Hyprland берёт `.lua`, если
он есть, иначе `.conf`. Значит достаточно убрать наш:

```bash
cd ~/dotfiles && stow -D hypr
```

Всё, система вернулась к штатному конфигу CachyOS. Никаких резервных копий не нужно.

## Часть 3. Что ты получишь

### Внешний вид

Монохром. Фон почти чёрный `#0f0f0f`, поверхности `#1a1a1a`, рамки `#2a2a2a`,
приглушённый текст `#6e6e6e`, основной текст `#e6e6e6`.

Два цвета на весь интерфейс:

- **Фиолетовый `#c678dd`** — только фокус. Рамка активного окна, активный воркспейс
  в панели, курсор в терминале, найденное совпадение в меню.
- **Красный `#ff6b6b`** — только критика. Заряд ниже 12%, неверный пароль,
  критическое уведомление.

Углы прямые, прозрачности нет, блюра нет, теней нет, рамки в 1 пиксель.
Шрифт везде один — JetBrainsMono Nerd Font Mono.

Смысл: если ты видишь на экране цвет, он что-то значит.

### Программы

| Программа | Что делает |
|---|---|
| **Hyprland** | раскладывает и рисует окна |
| **Ghostty** | терминал, быстрый и на GPU |
| **fuzzel** | меню запуска программ и выбора из списка |
| **mako** | всплывающие уведомления |
| **ranger** | файловый менеджер в терминале |
| **Firefox** | браузер |
| **Waybar** | панель снизу экрана |
| **hyprlock** | экран блокировки |
| **hypridle** | следит за бездействием: гасит экран, блокирует, усыпляет |
| **hyprpaper** | обои |
| **hyprsunset** | тёплые цвета экрана вечером |
| **cliphist** | история буфера обмена |
| **grim + slurp** | снимки экрана |
| **Neovim** | текстовый редактор (сборка LazyVim) |
| **asusctl** | профили производительности ASUS |
| **supergfxctl** | переключение режимов видеокарты |

### Панель снизу

Слева — воркспейсы 1–6, всегда видны. Активный подсвечен фиолетовым.

По центру — заголовок активного окна.

Справа, по порядку: название играющего трека, режим видеокарты, профиль
производительности, Bluetooth, громкость, сеть, заряд батареи, системный трей
(раскрывается по клику на иконку) и часы в формате `ЧЧ:ММ ГГГГ-ММ-ДД`.

Заряд становится красным ниже 12%.

## Часть 4. Клавиши

`SUPER` — клавиша с логотипом Windows.

### Программы

| Сочетание | Действие |
|---|---|
| `SUPER+Return` | терминал Ghostty |
| `SUPER+E` | файловый менеджер ranger в терминале |
| `SUPER+B` | браузер Firefox |
| `SUPER+A` | меню запуска (fuzzel) |
| `SUPER+V` | история буфера обмена |
| `SUPER+L` | заблокировать экран |
| `SUPER+Backspace` | меню питания: lock, logout, suspend, reboot, shutdown |
| `Print` | снимок экрана — сначала спросит «область или весь экран» |

### Окна

| Сочетание | Действие |
|---|---|
| `SUPER+Q` | закрыть окно |
| `SUPER+W` | сделать окно плавающим и обратно |
| `SUPER+P` | псевдотайлинг: окно занимает свою ячейку, но своим размером |
| `SUPER+стрелки` | перейти к соседнему окну |
| `SUPER+левая кнопка` + тащить | двигать окно |
| `SUPER+правая кнопка` + тащить | менять размер окна |

### Воркспейсы

| Сочетание | Действие |
|---|---|
| `SUPER+1` … `SUPER+0` | перейти на воркспейс 1–10 |
| `SUPER+Shift+1` … `0` | перенести окно на воркспейс |
| `SUPER+колесо` | пролистать воркспейсы |
| `SUPER+S` | показать/спрятать блокнот (специальный воркспейс) |
| `SUPER+Shift+S` | забросить окно в блокнот |

Блокнот удобен для того, что нужно держать под рукой, но не на виду:
музыка, мессенджер, заметки.

### Прочее

| Сочетание | Действие |
|---|---|
| `SUPER+Shift+W` | перезапустить панель, если она подвисла |
| Клавиши громкости | громче, тише, выключить звук, выключить микрофон |
| Клавиши яркости | ярче, темнее |
| Клавиши плеера | следующий трек, предыдущий, пауза |
| Жест тремя пальцами | пролистать воркспейсы |

### Закрытие крышки

- **На батарее** — заблокировать и уснуть.
- **На зарядке** — заблокировать и погасить экран.

Блокировка в обоих случаях специально: иначе закрытая на зарядке крышка не защищала
бы вообще ничего.

## Часть 5. Что происходит само

### Бездействие

| Через | Что происходит |
|---|---|
| 2,5 минуты | гаснет подсветка клавиатуры |
| 5,5 минут | гаснет экран |
| 6 минут | блокировка |
| 15 минут | уход в сон |

> **Про шифрование.** Обычный сон держит ключ шифрования диска в оперативной памяти.
> От человека с физическим доступом это не защищает — ключ стирается только при
> гибернации. Настройка гибернации это отдельная задача: нужен swap не меньше объёма
> памяти, параметр `resume=` в Limine и `resume_offset` на btrfs поверх LUKS.
> В README есть раздел, как это включить потом.

### Цвет экрана по времени

- с 7:00 — обычные цвета
- с 20:00 — 4500K, слегка теплее
- с 22:30 — 3500K, заметно теплее

### Видеокарта

В ноутбуке две: встроенная Radeon 880M и дискретная RTX 5060. Режимы переключаются
через `supergfxctl` или графическую `rog-control-center`.

Конфиг намеренно **не привязан** ни к одной из них. Если прибить композитор к NVIDIA,
то после переключения в режим Integrated сессия вообще не запустится. Поэтому
переключай режимы спокойно — конфиг переживёт любой.

Игры запускать через `prime-run`:

```bash
prime-run имя_игры
```

### Игры

Окна с классом `steam_app_*` получают три правила: экран не гаснет во время игры,
разрешены разрывы кадра ради меньшей задержки, запуск сразу в полный экран.

Учти: правило ловит только Steam. Игры из Lutris, Heroic или запущенные напрямую
имеют другой класс окна и под правило не попадут.

Также включены `vrr = 2` (адаптивная синхронизация для полноэкранных окон — панель
165 Гц с G-SYNC) и `direct_scanout` в режиме auto.

## Часть 6. Как это менять

Все файлы лежат в `~/dotfiles` и связаны симлинками с `~/.config`. Правишь в
`~/dotfiles` — меняется везде.

| Что менять | Файл |
|---|---|
| клавиши, окна, анимации, монитор | `hypr/.config/hypr/hyprland.lua` |
| таймауты бездействия | `hypr/.config/hypr/hypridle.conf` |
| экран блокировки | `hypr/.config/hypr/hyprlock.conf` |
| цвет экрана по времени | `hypr/.config/hypr/hyprsunset.conf` |
| панель: модули | `waybar/.config/waybar/config` |
| панель: цвета | `waybar/.config/waybar/style.css` |
| терминал | `ghostty/.config/ghostty/config` |
| меню запуска | `fuzzel/.config/fuzzel/fuzzel.ini` |
| уведомления | `mako/.config/mako/config` |

Hyprland подхватывает изменения конфига сам, перезапускать не надо.
Панель после правки — `SUPER+Shift+W`.

Сохранить изменения в репозиторий:

```bash
cd ~/dotfiles
git add -A
git commit -m "что изменил"
git push
```

### Полезные команды

```bash
hyprctl monitors         # что думает Hyprland про экран
hyprctl clients          # список окон и их классы (нужно для правил)
hyprctl configerrors     # ошибки конфига
hyprctl devices          # устройства ввода, включая переключатель крышки
supergfxctl -g           # текущий режим видеокарты
asusctl profile -p       # текущий профиль производительности
brightnessctl -l         # список устройств подсветки
```

## Часть 7. Первые дни

**Не пытайся выучить всё сразу.** Достаточно пяти сочетаний: `SUPER+Return`
(терминал), `SUPER+A` (меню), `SUPER+Q` (закрыть), `SUPER+цифра` (воркспейсы),
`SUPER+B` (браузер). Остальное придёт само.

**Обновляйся регулярно, но не перед важными делами.** `sudo pacman -Syu`.
Arch — rolling release, и обновление иногда что-то ломает. Не запускай его за час
до дедлайна.

**Не копируй команды из интернета вслепую**, особенно с `sudo`. И помни, что
большинство гайдов по Hyprland написаны под старый формат `hyprland.conf`, а у
тебя Lua.

**Если что-то не работает** — начни с `check.sh`, потом `hyprctl configerrors`,
потом лог:

```bash
tail -60 ~/.local/share/hyprland/hyprland.log
```

### Чего этот конфиг не делает

Он не настраивает звук, polkit, порталы xdg-desktop-portal и экран входа — этим
занимается CachyOS, и лезть туда незачем.

Он написан **без доступа к железу**: ноутбука не было, когда его писали. Все имена
настроек сверены с исходниками программ тех версий, что стоят в репозиториях, но
четыре вещи проверяются только на живой машине — режим экрана, имя устройства
подсветки клавиатуры, имя переключателя крышки и поведение разрывов кадра на NVIDIA.
Именно их и проверяет `check.sh`.
